## 阅读口径

正文将研究假设与实验结论分开。工作稿和早期行为审计保留历史记录；原角色协议见 [角色训练结果](role_training_results.md)，最新共同中继与任务年龄协议见 [中继训练结果](relay_training.md)。开发验证、固定协议独立测试与正式多重复实验必须区分，不能将单个训练种子或几个案例上的优势写成“显著优于现有算法”。旧 8 星短场景只作场景失效诊断。完整复现卫星论文与适配其学习组件也必须区分。

优先读第五章和待办表：它们决定后续是否能够支撑第四章的方法设计。暂不扩展硬件、可视化产品或新的应用场景。
