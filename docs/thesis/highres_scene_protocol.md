# 高分区域成像场景与实验口径

更新：2026-10-15。研究问题是：少量高分遥感星在美国民用研究区域成像，能否利用星间计算和中继，更早在中国接收端得到完整图像分析结果。本文描述网络层仿真；不代表真实星座已集成这些设备，也不是星载 GPU 实测或最终 MARL 成绩。

当前执行口径以用户批准的[冻结清单](../../results/sla_frozen_protocol_20261015/manifest.json)为准：两跳星上输入卸载、原图中继到地面、0.1秒仿真步长，仅保留原三日`s3_gap30`负载。主指标为日等权P300，次指标为日等权R300；后续研究范围和停止条件见[工作简报](../codex_brief.md)。[T1报告](../../results/sla_frozen_t1_20261015/REPORT.md)证明这三日实例的最大按时计数对应91.6340%，当前CGS适配为89.6732%；不是统一在线算法或时延最优证明。下文保留参数选值由来和首轮诊断，历史条件不替代冻结配置。

## 1. 轨道布局为何分成两种

起始方案将2颗成像星与22颗辅助星放在两个620 km、97.9度轨道面，每面12星。几何核查发现：10月15日美国白天的21次成像之后，整个星座4小时内都没有北京接收窗口。这个负结果保留在[几何审计](highres_geometry_audit.md)，不能用它证明调度算法优劣。

第二种布局保留完全相同的两颗成像星，只把22颗辅助星改为两个550 km、53度轨道面，每面11星。成像星采用类太阳同步轨道，辅助星采用独立中倾角低轨层，目的是提供不同地方时的传输机会。这是研究架构对照，不是实际运营星座的复刻。源星 ID 在该配置中为0和1，辅助星为2至23。

| 配置 | 取值 | 依据与边界 |
|---|---|---|
| 成像源 | 2颗；620 km；97.9度 | 高度、倾角参考Pléiades Neo；两颗源星数量与研究问题一致 |
| 成像轨道面 | RAAN 357.5/12.5度；相位0/15度 | 合成研究选值，近似上午下降轨；实际成像仍逐次检查太阳高度 |
| 专用辅助星 | 22颗；550 km；53度；2面×11颗 | 独立低轨计算中继层设计；11颗均布时相邻沿轨距离约3904 km，可落入4500 km研究截断 |
| 辅助轨道面 | RAAN 0/90度；Walker相位参数1 | 预设几何，未按策略结果搜索；需后续跨日期和轨道相位重复 |
| 接收端 | 北京坐标39.9042N、116.4074E；最低仰角15度 | 中国境内单站研究假设，不是实际北京站天线验收参数 |
| 星间邻居 | 每星最多4；距离≤4500 km；地球无遮挡 | 终端数量及距离为研究假设；按距离确定性匹配，不依赖任务负载 |
| 时间 | 固定2026-10-15起，后扩展连续3天 | 所有自然日内合格事件都保留，不按策略输赢选择日期 |
| 接入状态 | 拓扑、地面可见性每10 s刷新；接触预测30 s采样 | 数值近似；短窗口及边界有误差，不能冒充连续精确接触 |

同一高度不等于相同地面轨迹；不同倾角轨道的相对节点进动也不同。三天实验仍不是长期覆盖证明。激光捕获时间、终端跟踪角速度和姿态限制未得到设备级闭合验证，详细边界见几何审计。

## 2. 通信参数为何这样取

星间主档为SCOT80公开通道规格10,000 Mbps，低档对照2,500 Mbps；星地为Pléiades Neo双X波段通道**合计**1,200 Mbps。地面只允许同时接收一颗星的聚合数据流，不能把双通道再次乘二。具体原文与链接见[通信参数证据](highres_link_evidence.md)。

满足几何条件时采用恒定速率，不再添加没有链路预算依据的正弦波或距离衰减。主档效率1.0是业务容量理想上限，0.8为额外吞吐损耗敏感性假设；两者都不是已测端到端净吞吐。每星同时装四套兼容终端、计算星也配备该级别下行、地面站配额，均是架构假设。当前能耗模型未按这些设备校准，本轮不做真实能效结论。

## 3. 图像、压缩和 overlap 账本

影像参考14 km幅宽、0.3 m全色、1.2 m六波段多光谱、12 bit数据。20 km条带长度是研究选择。整数栅格采用46668×66668全色像元，多光谱为11667×16667像元。

| 对象 | 数值 | 解释 |
|---|---:|---|
| 未压缩全色+多光谱 | 6416.978337 MB | 逐组件12 bit紧凑打包；不是RGB原图 |
| 压缩后唯一影像 | 2138.992779 MB | CORECI2公开3至大于6倍范围内选择3:1；具体图像压缩率与质量尚未实测 |
| 模型窗口 | 1024×1024，步长824 | 固定200像素重叠；末窗贴边可能更重叠 |
| 窗口数 | 4617 | 所有窗口均参与计算和任务完成判定 |
| 调度包 | 至多4×4窗口；315包 | 打包与推理窗口不同；边缘包可能少于16窗口 |
| 最大包 | 11.534336 MB | 多光谱窗口按低分辨率坐标向外取整，计入重复像元 |
| 全部分片传输量 | 3328.376832 MB | 相对唯一影像增加约55.60%，来自重叠重复打包 |
| 结果代理 | 0.863379 MB/幅 | 旧RGB检测样本的187 bytes/window外推，未做本高分条带目标密度测量 |

模型的RGB8输入显存与原生PAN/MS传输格式分别记账。当前只模拟其工作量，不执行原生影像解码、融合、辐射校正和检测；不得把模型窗口RGB输入说成传感器直接输出。压缩不保证无损或检测准确率不变。

最大包在10 Gbps星间链路上纯序列化约9.227 ms，在1.2 Gbps星地链路上约76.896 ms；整幅唯一影像理想下传约14.260 s，含重叠分片约22.189 s。对冻结首日的完整窗口审计显示，331个星间窗口和32个星地窗口空载时都能容纳整幅分片，见[窗口审计](../../results/highres_contact_audit_20261015.md)。这证明当前包长不受完整窗口容量限制，不能证明拥塞或临近断链时一定传完。

## 4. 算力、缓存与尚未标定的时间

每1024窗口计算成本0.07026846145参考秒，来自既有M5 Pro同机CPU检测测量；对应MPS参考服务率为3.23968270566倍。所有星节点先取同一参考能力1，地面取3.23968；每幅星上串行参考计算约324.43 s，地面约100.14 s。另将地面能力乘10，检验更强服务器假设。这些是工作量代理和敏感性，不是Jetson、星载GPU或服务器实测。

每星64 GB数据缓存、1 GB推理显存额度和0.8 GB单窗口基线为明确的研究配置。64 GB容纳多幅完整分片及中继突发，避免继续沿用小图配置的几百MB缓存；它不是公开设备DDR容量。星上实际批处理、并行GPU执行、解码/重新压缩、PAN/MS到模型输入的转换，以及大图全局NMS耗时仍需测量。当前固定聚合延迟来自旧小图样本，仅作占位，不能据此解释亚秒差异。

## 5. 成像事件与配对方法

对美国五个农业/植被研究区域，按10 s采样的轨道传播、最大30度离轴角、太阳高度至少21度（含1度设计裕度）生成事件；每源每次区域过境最多3幅，所有区域共享至少30 s的成像间隔；同一源星对同一区域的两个窗口首幅之间另需至少600 s。区域和到达强度属于研究需求假设，不是运营订单。云量、姿态机动和整条带足迹尚未模拟，成像作为任务释放事件处理。

当前冻结开发集为连续三日`s3_gap30`，分别释放21、15、17幅图。每个自然日从首条合格成像事件前120秒开始，起点不早于当日零点，保留当日全部合格事件；最后释放后至少观察301秒，足以核算所有任务的P300/R300。超时任务继续竞争资源，不主动取消。该观察期不支持最终完成率或600秒交付率结论；首轮最后任务后4小时的运行只用于历史长尾诊断。各方法拿到相同配置、轨道和任务哈希，三天按日从空队列开始，没有跨日残留队列，不能当作72小时连续运营仿真。窗口预计算仍延伸覆盖观察结束后的完整7200秒预测范围。

| 方法 | 含义 |
|---|---|
| `ground_compute` | 源星等待直达中国站，唯一原图完整接收后地面计算 |
| `ground_tiles` | 分片直接下地，可流水计算；不经其他星中继 |
| `ground_relay` | 原始分片可经多星传至地面，全部推理在地面完成 |
| `local` | 源星本地计算，结果可多跳中继回地面 |
| `greedy` | 按当前资源估计完成时间选择计算位置；能否利用共同执行器的全部候选能力取决于策略实现，结果共享同一中继机制 |
| `window_aware` | 在估算中加入本地/候选计算节点的地面窗口；没有因此变成最优多跳联合规划 |
| `heft_adapted` | HEFT式排序及资源时间表在动态分片系统中的适配 |
| `cgs_compute_adapted` | 接触图路径估计与计算放置的适配，在当前公共执行器中比较本地、至多两跳计算星和原图中继至地面的交付报价；非原论文完整复现 |

首轮四小时观察中直接下地组无源星窗口，仅作几何对照；当前主要地面对手仍为`ground_relay`。现有原始分片中继仍发送重复overlap像元，尚未实现“原图无重复分块中继、地面重组后生成overlap窗口”的更强基线。该缺口应在论文结论中披露，不能声称优于全部可能的地面方案；补充该执行能力需要按工作简报先确认协议变更。

每秒一次星上决策，统一最多每星64包；旧MARL固定每星4包，本轮没有将旧模型强行作为同口径成绩。输入计算卸载使用至多两跳星间路径，原图中继到地面与结果中继最多八跳；实际传输计入逐跳字节、缓存、链路竞争与目标计算承诺，不是瞬时远程计算。原图地面中继同样开放给混合计算策略，`ground_relay`对照则固定全部在地面计算。公共路由动态重算，预测报价不等于已锁定的执行路径；22颗辅助星不等于每次成像都可直接调用22颗计算星。当前配对策略使用全拓扑预测和公开队列、未计控制信令时延，不能称为受限局部信息的分布式MARL验证。后续训练需统一可决策吞吐与观测信息。

## 6. 指标、数值敏感性与复现

完成定义为同一整幅图全部窗口结果在地面齐备并完成固定聚合。不以完成部分分片或仅原图到地面替代完整任务。当前P300为释放后300秒内完成的整图数除以全部释放整图数，R300为全部任务的截断平均时延，失败、迟到或未完成均计300秒；按日等权汇总，另列任务合计。首轮5、10、30、60、120、240分钟曲线、六时限J与4小时截断平均时延只保留为历史诊断，不能与当前冻结指标混表。

5分钟是本研究已冻结的业务SLA选择，不是遥感行业统一标准。当前采用超SLA仍继续运行的口径，硬过期取消会改变资源竞争，需要先确认协议变更再统一重跑。定义和文献适配边界见[短时限协议](short_deadline_protocol.md)，当前逐任务记录与证据哈希以[冻结清单](../../results/sla_frozen_protocol_20261015/manifest.json)为准；[首轮短时限报告](../../results/highres_short_sla_20261015/REPORT.md)属于一跳、粗步长历史版本。

当前冻结主时间步为0.1 s，星上决策周期仍为1 s，真实拓扑与地面可见性每10 s刷新，接触预测30 s采样、60 s更新。计算采用`work_conserving`，网络允许同一步内重新分配短流剩余容量。首轮使用1 s；曾对首个成像窗口的3幅图比较1、0.5、0.25、0.1、0.05 s，保持策略决策1 s、几何更新10 s不变。原始中继每个执行步重选路，因此步长同时影响其控制频率。

该首轮诊断发现并修复了“先求无约束最短路、再过滤跳数”漏掉可行路径的错误，详见[路由修正记录](highres_routing_correction.md)。修复后的原始中继在上述五个步长下平均时延分别为190.00、194.00、195.42、177.10、186.50 s，三幅图均在5分钟内完成。旧0.1 s运行的1732.4 s异常值仅保留为错误诊断，不混入后续比较。后续两跳模型的15图前缀又发现1 s会让临界结果错过地面窗口；0.1/0.05 s的按时集合相同，但该局部证据不能宣布全部场景数值收敛，见[步长诊断](../../results/sla_twohop_window_timestep_20261015/)与[0.05秒复核](../../results/sla_twohop_window_timestep_005_20261015/)。固定10 s几何与零激光建链时间仍是独立误差源。以上公共模型修正均不能计为候选算法收益。

```sh
.venv/bin/python analysis/audit_highres_contacts.py --help
.venv/bin/python -m unittest discover -s tests -v
```

每次运行保存配置、成像窗口、任务轨迹、源码及分析脚本哈希、完整任务结果。[首轮高分实验报告](../../results/highres_fixed_study_20261015/REPORT.md)与修复前报告均按各自版本保留，不能无标注混用。当前唯一参数与结果入口为[冻结清单](../../results/sla_frozen_protocol_20261015/manifest.json)，后续操作记录进入[统一实验日志](experiment_log.md)；T1已触发改善空间不足5个百分点的停止条件，当前不继续压力扫描或训练。
