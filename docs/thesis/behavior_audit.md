# 当前候选策略行为审计

日期：2026-10-08。结论：当前 checkpoint 在三个开发验证场景中的确定性动作全部为 LOCAL，未表现出星间卸载或地面计算。

## 实验与证据

- 配置：`examples/config_training.yaml`，24 星、2 小时、10 秒步长。
- 候选：`checkpoints/calibrated_task_attention/best.pt`，训练种子 7、两轮训练。
- 配对策略：`local`；验证种子 10001、10002、10003，未使用预留正式测试种子。
- 原始产物：`results/behavior_audit_20261008/summary.json`，每次运行目录保存 `actions.jsonl`、`events.jsonl` 和指标。
- checkpoint、审计脚本、模拟器源码、配置、任务轨迹及 TLE 均有记录或哈希。

候选没有 WAIT、ISL 或地面卸载提案，实际 ISL 发送量为零。在候选每一步的相同状态上查询 local，动作差异为零。配对运行到达轨迹一致，完成任务 ID 集合一致，新增与损失任务均为零。当前结论强于“汇总指标相同”，但仍只覆盖这三个场景的访问状态和确定性推理。

提案会对等待中的同一分片重复出现，4400 不是任务数或分片数。脚本分别统计动作提案、实际生命周期事件和完成任务上的协同路径，避免把未完成传输算成协作成功。事件的 `time_seconds` 是步开始时刻，精确完成时延使用模拟器指标。

## 对后续工作的影响

728 个分片全部完成源星计算，最终交付 280 个分片；448 个未交付分片对应 56 个未完成任务。本次轨迹表明本地策略的主要未完成环节在计算后的交付，而不是尚未处理的计算队列。现有动作只允许转移未计算原始分片，结果不能经邻星中继；原始图像与结果数据量比例为 256:1。这些因素可能让原始分片卸载代价较高，需用可执行案例和等待时间分解验证，不能仅凭上界断言存在很大可实现收益。

优先动作是证明一种可执行调度在某些具有业务依据的开发场景中能够超过 local，并解释它靠什么完成额外任务。若需要新增结果中继，必须将其明确为问题定义变化，对所有方法统一开放并重跑基线。不要通过直接奖励 OFFLOAD 比例制造看似协作的行为。

后续更新：已在相同 24 星场景中验证可执行协同机会，固定任务目的地的诊断对照完成 39/91，相比 local 新增 4 个任务且无损失。参见 [协同收益与瓶颈诊断](cooperation_feasibility.md)。这不是 MARL 改进结果；本页对原候选模型的审计结论仍成立。

## 重现

在仓库根目录运行，输出目录必须不存在：

```bash
.venv/bin/python audit_policy_behavior.py --config examples/config_training.yaml --checkpoint checkpoints/calibrated_task_attention/best.pt --seeds 10001,10002,10003 --output-dir results/behavior_audit_repeat
.venv/bin/python -m unittest discover -s tests -v
```

本次 37 项测试通过。行为审计只诊断现有模型，不修改策略、训练奖励或模拟器语义。
