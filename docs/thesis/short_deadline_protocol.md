## 任务完成与指标

任务释放时刻r_i是完整影像获取结束并成为可调度任务的时刻；
完成时刻C_i是所有必需窗口的结果在地面齐备且完成聚合的时刻。
既可以原图送地面算，也可以星上处理后回传结果。原图刚到地面不算处理完成。
overlap、处理模型和输出质量要求对各方法一致。

```text
L_i = C_i - r_i
P_300 = sum(1[L_i <= 300]) / N
R_300 = sum(min(L_i, 300)) / N
```

N包含所有释放任务，失败、迟到及未完成任务不删除。未完成的L_i为无穷，
在R300中计300秒。恰好300秒完成计按时。P300越高越好，持平时R300越低越好。
5分钟是本研究业务SLA选择，不是遥感行业统一标准或由设备规格推导的常数。

多日期对每日指标等权，另列池化按时数量/总数。零到达日期报告不适用并保留日期，
不置0或1、不替换；全空面板报告无法评价。任务不能当作独立轨道重复。

## 冻结执行与观察

当前仅2026-10-15至17日的s3_gap30开发负载，分别21、15、17个任务。
两跳星上输入卸载、原图地面中继、结果中继共同开放；dt=0.1秒，
决策周期1秒，真实几何采样10秒。其余精确参数见冻结清单。

`deadline_steps=0`：超过300秒仍继续处理和竞争。不能通过硬取消或删除迟到任务
释放资源后，拿结果与本协议直接比较。每个日期独立初始化，观察至最后释放后至少
301秒，未来窗口预计算仍覆盖完整lookahead。只对全部任务有完整随访的300秒指标
作结论；当前短尾观察不能报告全体任务的600秒交付率或最终排空完成率。
历史4小时观察、1秒积分及1/2/3/5/10分钟曲线不属于当前主表。

任务释放前的真实成像、压缩、解码和PAN/MS预处理尚未实测；
固定聚合延迟及CPU/MPS算力均为代理。不能宣称已验证成像开始到终端用户的完整实测时延。

## 公平比较

所有适用策略共享任务、轨道、链路、缓存、信息权限、候选额度、计算服务和中继规则。
原始输入与结果真实竞争链路及地面通道；路径预测不等于按该路径固定执行。
所有策略参数只在开发数据上选择，报告每个任务相对基线新增/丢失按时状态。

| 方法 | 当前定位 |
|---|---|
| CGS计算机会适配 | 当前最强日期等权P300基线；逐分片最早完整交付规则，非原文完整系统 |
| HEFT适配 | 异构处理器选择核心已验证，公共执行器中的在线适配 |

| 全地面原图中继 | 应用对照；仍需核对无重复overlap原图下传及服务器标定 |

## 开发结论与停止条件

[T1报告](../../results/sla_frozen_t1_20261015/REPORT.md)认证这三日实例的最大按时计数
为21、13、15，日等权91.6340%；CGS为21、13、14，日等权89.6732%。
每个日期分别有完整实际运行达到其窗口上界，不是逐任务拼接，也不是统一在线最优算法。
剩余完成率空间最多1.9608个百分点，已触发简报的停止条件。

研究范围或贡献重点待用户确认。不能自行增加压力条件、变更主指标或公共执行语义；
不把公共两跳、混合中继和步长修正的跨版本提升算作候选算法收益。
