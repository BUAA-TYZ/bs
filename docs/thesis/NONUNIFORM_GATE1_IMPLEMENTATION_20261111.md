## 任意分组与内存

规范窗口顺序按y后x；映射为每窗一个整数块标签，标签必须连续0..K-1，1<=K<=16，每块非空。任意非平方K合法，不再从K猜方形网格。
块输入按各原生分量把窗口坐标以downsample向外取整，再计算所有矩形的真实并集面积，按bands和位宽每分量向上取整字节，求和后应用原固定压缩比。不同块重叠保留；不使用包围框、不逐窗简单相加。
每窗计算量与原窗口绑定、求和守恒。实际结果字节从原event.window_result_bytes按规范坐标绑定，各块相加；策略估算只使用公开单窗结果代理。G继续旧唯一原图分包，与C_nu互斥。
提交仅允许整图所有旧块在源星QUEUED且无已承诺计算/传输；源星内存原子替换。相同分组重复提交幂等，冲突拒绝。提交后分组和目标不变，接纳延迟只向原目标重试动作，可重新求合法输入路径，不改变分配。
单块准入上限采用现有M config.mem_capacity_gb（各任务实际配置哈希冻结），源星还核验替换后总内存，计算星按剩余内存，中继沿原reserve_input_memory逐跳预留。地面旧执行器未显式建模输入RAM，本候选额外使用相同mem_capacity_gb数值作为有限单块接收配额；不把缺字段解释为无限，不宣称测得地面RAM，也不改变旧五候选或地面总算力。

## 候选与份额算法

1. 在当前全局合法状态、同决策已承诺日历下，通过旧CGS input_options取得一窗口输入可达的位置（源星/计算星/地面），并检查结果能按公开计划回到地面。以一窗口预测完成最早排序，稳定节点ID破同分（卫星数值ID先，地面字符串ID后），保留最多16个。不是按验证性能选目标数。
2. 对每目标建立n=0..W的预计完成表，F(0)=0。输入量用规范行蛇形的前n窗口精确并集；这是统一几何代理。用一窗口选出的固定CGS路径重新按输入字节估计到达，检查接触容量和内存，再加入已承诺忙时、现有单窗/cohort服务规则及公开结果代理回传。地面计算沿原总算力口径。
3. 原始离散报价可能非单调，使用前缀最大值上包络Fbar(n)=max(Fbar(n-1),F(n))保证二分容量单调。n首次不可行记正无穷，后续保持不可行；不假定原离散接触报价天然单调。
4. 搜索区间下界0，上界min(3600秒,当前接触计划各contact.end+delay最大值)，均相对当前决策。没有可用上界或上界总整数容量不足W则候选不可行。二分最多64次，hi-lo<=0.01秒停止；容量为Fbar(n)<=T的最大整数n。
5. 先取lo处容量；若因零时平台容量超过W，则从全零开始。余窗逐个分给下一窗预计完成时刻最早且<=hi的目标，目标排序破同分，直到恰好W。无可行余窗则拒绝；零份额位置不建块。这个整数近似不承诺各块实际同时完成。
6. 按下述三种几何映射择一，再对真实分组字节重新求输入路径并检查内存。原Calendar.quote共享接触日历完整报价，同时保留CGSTaskChoice整图复核，二者都可行才接受，取较大整图报价。源星内存、映射后输入、共享报价任一不可行则记录原因，退回原五候选。
7. 与L4/L16/C4/C16/G一起选择，报价并列依次L4、L16、C4、C16、G、C_nu；新增最后。原五候选语义不修改。仅胜者日历及分组提交。

独立份额估计不提前共享预留各目标输入/输出，因此可能乐观；实际映射与行蛇形前缀也可能字节不同。最终共享复核不能消除原FIFO日历的容量互斥近似、窗口执行调度、后续任务竞争和结果代理误差。上述都作为限制及误差来源候选，不据此预言结果。

## 三种映射（只看几何）

目标顺序固定为上述候选排序删去零份额后的顺序，不运行后按性能重新排序。每种排列按各目标整数窗口数连续切段，一目标一块。

1. 按行蛇形：行从上到下，偶数行x递增、奇数行x递减，左上开始。
2. 按列蛇形：列从左到右，偶数列y递增、奇数列y递减，左上开始。
3. 沿长边条带：宽>=高（正方形同分取水平）时，各横行自上而下，每行从左到右；高>宽时，各竖列自左而右，每列从上到下。份额边界可在条带内切开，仍精确满足窗口数，不额外复制或舍弃窗口。

三种映射分别按实际窗口组计算块输入并集字节总和，取最小值，同分依次上述1/2/3。不查仿真性能、不查询结果真值。保留各候选映射字节；分别报告评分图可行C_nu候选及最终选中C_nu的映射比例、块数分布、相对同份额仅行蛇形的总字节变化。暖机记录保留，主诊断不混入评分图分母。
