- 输入固定 `[1,254]`，输出 `[1,4,12]`，仅支持此次验证的 batch=1。
- 28,417 个参数；FP32 参数为 113,668 B，TorchScript 文件为 139,686 B。
- 十个随机同形输入经 `torch.testing.assert_close` 与完整模型的策略 logits 比较通过。
- 追踪器对 `len(obs)` 给出动态 batch 警告；不保证其他 batch 尺寸。
- 推理计时为本机 CPU 单线程，50 次预热、500 次重复。中位数 0.0658955 ms，P95 0.07625 ms。
- 计时仅包含网络，不含特征、星历预测、动作 mask、运行内存或通信成本；不是星载或地面服务器测量。
