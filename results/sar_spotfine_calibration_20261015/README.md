## 测量记录

设备为Jetson AGX Orin Developer Kit，系统可见32188686336 B共享内存，JetPack6.0、CUDA12.2、PyTorch2.3.0、Ultralytics8.3.13。保留原MAXN模式，未修改时钟、功率或软件包。正式网络参数及输入为float32，cuDNN允许TF32，matmul不允许TF32；不能称禁用了TF32。

三轮独立进程各50次预热、64次计时，均值分别576.100742、561.069024、572.975942 ms。持续运行另预热50窗，900.219257 s内完成1562窗，全程活跃服务均值573.967599 ms。最后五个完整分钟各完成104窗，满足预登记的分钟吞吐偏差不超过5%标准。循环窗口不算新增独立SAR影像样本。

末300秒tj传感器范围61.812–63.125摄氏度，趋势约+0.098摄氏度/分钟。遥测没有GPU MHz字段，因此只确认本次有限时段吞吐稳定，不认证完整热平衡、GPU频率稳定或在轨散热可行性。没有受控空闲功率基线，不计算单任务增量能耗。

计时输入是固定种子的合成uint16幅度阵列，归一化至uint8后复制三通道；固定官方光学YOLO11n-OBB只作计算代理。网络输出传回CPU，但SAR后处理负载使用独立的受控100候选NMS、目标ROI预览及SRP1编码。预处理、传入、前向、传回、NMS、预览编码的末段周期均值依次为23.032、11.346、456.414、5.386、49.300、28.368 ms。真实光学预测不用于估计SAR精度或输出密度。

输出夹具包含100个合成目标、212条跨窗重复记录，64包共55,589,040 B。地面聚合保留100个目标，输出26,220,428 B，正反到达顺序均得到相同几何与哈希。聚合预览是全零占位字节，只测解析、复制和重编码。SAR聚焦、文件解码、识别精度、真实港口密度与飞行环境均不由此实验验证。

## 文件与复算

- `workload_fixture.json`：固定几何、目标、64窗与字节清单。
- `jetson/series/`：三轮、持续运行的逐窗JSONL、报告、控制日志与1136条遥测。
- `jetson/aggregation/report.json`：聚合原始20次计时、正确性及到达顺序验证。
- `jetson/probe/`：正式测量前的短时可行性检查，不参与最终服务率选择。
- `calibration_summary.json`：核验后的正式服务率、选择区间、分阶段耗时、局限和来源哈希。
- `../sar_spotfine_frozen_20261015/main_config.json`：统一算力的主仿真配置。

从仓库根目录复算，输出选择新文件，保留已有测量：

```bash
.venv/bin/python analysis/summarize_jetson_sar.py \
  --series-dir results/sar_spotfine_calibration_20261015/jetson/series \
  --aggregation-report results/sar_spotfine_calibration_20261015/jetson/aggregation/report.json \
  --output /tmp/sar_calibration_recomputed.json
```
