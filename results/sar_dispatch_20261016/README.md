# 固定推理工作量的分组调度与空目标回传

日期：2026-10-16。用户授权开始接入并验证。

## 已实现

- 当前主配置16个调度块，每块通常含4个4096像素推理窗口；总计仍64窗。
- 包内原生uint16像素去重，跨包重叠仍传输；800 MB整图对应1.287882752 GB分片输入，最大块81.92 MB。
- 星上按窗口组执行：单窗0.597 s、双窗组1.056 s。可在同一大块内并行，也可把块尾窗与下块首窗配组。
- 部分完成的大块留在原计算节点，输入缓存保留至全块计算结束，执行显存按并发窗数占用。
- 结果在整块内部所有窗口完成后才可中继；任一窗口未完成或任一结果块未落地，整图都不计完成。
- 每个空窗口返回28字节完成头；非空窗口按每条目标记录40字节、ROI头20字节、512x512 uint8预览核算。
- 同一目标在overlap窗口内的重复记录仍发送，地面统一聚合，不额外宣称星上目标去重收益。
- 原始图像地面计算路径保留，唯一像素原图中继仍只上传800 MB，然后执行全部64窗对应工作量。

64/16/4块分别传输2147.483648/1287.882752/949.782528 MB；每幅图总结果字节和推理工作量相同。
16块比64块的分片输入量降低约40.03%，这是几何字节量，不是整图时延或完成率收益。
地面仍为单星饱和吞吐10倍，整图纯计算3.3792 s。两路邻星、星间2 Gbps净载荷、星地960 Mbps保留。
硬件标定和链路来源沿用`../sar_parameter_contract_20261016/`；未重新跑Jetson或改论文。

## 输出负载与信息权限

`output_workloads.json`是明确的合成业务负载，不是SAR实测标注：从原100个非碰撞合成船体中，
每非空图固定抽取30个，另以0.1概率产生全空图。随机序列由种子、任务索引、源星和释放步固定，
与调度策略和分组大小无关。原船体几何与上下文满足原overlap包络；不验证识别精度。

180图实际生成14张全空图，11520窗口中4230为空，平均每图结果15.454347733 MB。
同目录`empty_config.json`和`dense_config.json`用于输出量敏感性；所有条件的推理计算量保持不变。
固定计算成本保留了原受控输出测量中的后处理开销，是保守的计算代理，不宣称空窗CPU耗时已经实测。
算法在计算完成前只看到该负载模型的总体期望结果大小；真实输出量只在整块计算完成后揭示。
不依据真实空目标跳过推理或提前选择小输出任务。未知类别仍是目标记录，不按空窗处理。

## 短场景结果

`smoke/`覆盖开发日起1040秒，4图分别在565/595/625/715秒就绪；dt=0.01 s。
所有图都有至少300秒观测期。该前缀只用于接入和数值诊断，不能代表全天排名。

| 方法 | 16块按时数 | R300秒 |
|---|---:|---:|
| 唯一原图中继到地面 | 1/4 | 233.1775 |
| 本地计算加结果中继 | 1/4 | 235.6775 |
| CGS计算适配 | 0/4 | 300 |
| HEFT适配 | 0/4 | 300 |

`smoke_64/`使用完全相同的到达、目标输出、链路和算力，只改为64个调度块。
四种方法的按时数与R300均与上表一致，两个分组下共8次运行全部通过执行守恒检查。
因此本次只确认输入几何字节减少40.03%，尚未观察到按时率或截断时延提升。
不能把不同运行的主机墙钟差异当作星载计算加速。

4种运行的工时、窗口、字节与时间戳检查均通过。新网络两邻星配置不与旧四邻星结果混为同一实验。
`diagnosis/`确定性重放CGS，逐任务结果与短跑完全一致。第一张图16块已算完，15块落地，
一块仍处于COMPUTED状态；其他任务存在GROUND_RELAY_PENDING以及结果已转发7-8跳仍未落地。
这是路由与尾片交付待核查的证据，不足以单独证明是8跳上限、动态路径重选或终端选择中的哪一项导致。
不能通过改大算力、修改成功分母或隐藏空图来消除失败。

`day_bound.json`检查了全部180图：零计算、零传输耗时、无限带宽/缓存、不限跳数、多副本传播的
松弛上界为163/180，另17图在300秒内无到北京站的时序路径。真实算法只能低于或等于此上界；
主场景分母仍保留180图。短场景4图在此松弛下都可能按时，不等于有限资源和8跳协议下必定可行。

## 后续实验边界

64块同负载短对照和CGS确定性回放已完成；当前不把4图的结果写成全天结论，也不直接启动长训练。
只有明确路由执行口径后再开展全天CGS/HEFT/强地面对比，测试日期保持封存。
标称到净载荷的0.8效率为假设；激光捕获/重指向、传播、整星功率/热/SAR占空比仍未工程验证。
不声称当前两路终端平台已经满足整星能源设计，不伪造实际低轨终端效率或港口船流密度。
