# 学习型整图方案选择器提案（不超过一页，待确认）

**定位与接口。** 保留冻结 v3 的三套方案生成器、可行性约束与执行器，仅学习选择本地、CGS 或原图地面方案，修正报价偏差。每颗源星独立调用同一个共享参数的小型 MLP，不按卫星编号训练独立模型。输入为本星图像年龄/工作量、三报价及有效性掩码、各方案涉及节点的公开队列/内存与接触余量；不得使用未来到达、计算前真实结果字节或其他私有状态。保留 v3 同轮确定性提交顺序与资源检查；信息广播成本仍为未建模假设，不能宣称严格分布式通信性能。初版以分类交叉熵学习标签；不训练 MARL、不改三套规划器。该组件属于多源星共享策略的监督式选择器，不冒称多智能体强化学习。

**反事实标签。** 在开发回放中记录某图首次整图决策前的完整执行状态及 RNG 状态，从同一状态复制三条分支，分别只强制该图采用一套方案，后续其他图继续运行固定 v3，三分支使用同一外生到达与输出真值。比较该图实际完整落地时间，已观测最快者为标签；并记录三条实际时延及与报价的差。真实未来只在离线回放器产生标签，绝不进入 actor 特征。各分支最多回放 7200 仿真秒；若已有完成分支比其他分支的删失下界更早，可确定赢家；否则标为不可判定，不以预测值或 300 秒截断平局充当最快标签。记录不可判定比例，精确平局沿用 v3 顺序。同状态干预会改变后续资源竞争，标签只针对固定后续策略，不是三种纯策略整日成绩的拼接。

**日期、规模与成本。** 训练只用 **2026-10-15 至 10-21**；验证只用预登记 **10-22 至 10-24**。只取五个正式条件；按固定种子、日期/条件分层，每格最多均匀选 8 个首次整图决策，共最多训练 280、验证 120 个状态，最多 **1200 条分支回放**。先验证状态克隆及确定性重放；不支持快照时按原历史重放前缀并计时。分支上限合计约 100 个仿真全天，按本轮开发估时约 39 worker 小时，另有最多 50 个日期条件前缀生成约 20 小时，以及序列化/审计开销；规划约 **60–120 worker 小时**，是估算而非免费标签。小样本不足或删失过多须如实报告，不擅自扩充测试数据。12-01 至 12-06 和旧光学 11-21 至 11-26 均禁止用于训练、标签、特征选择或验证；本轮正式测试已消费，后续学习方法需要另行预登记、授权的新盲测才能宣称独立测试效果。

**对照与判定。** 相同输入权限、可行性及提交顺序下比较 v3 规则选择、均匀随机可行方案选择、学习选择，以及同状态反事实最快方案。事后最优仅是该决策状态和固定后续策略的局部上界；存在任务干扰，不能将逐图最优拼成可实现的整日全局上界。报告验证日等权 P300/R300、逐日增减、选择错误率、实际/报价误差、决策耗时和标签覆盖率；性能主次仍是 P300 优先、R300 次之。保留三方案报价意味着不预设能大幅降决策耗时，也不保证超越 v3。

**时间盒与停止。** 10-25：快照/标签审计及少量计时；10-26 至 10-28：开发标签与训练，至少 **1701、1702、1703 三个种子**；10-29 至 10-30：冻结模型后的验证与对照；10-31：汇报并停止。失败或无收益照实记录，不据正式测试结果改方法、不延长时间盒。**本提案尚未实现、未生成学习标签、未训练；等待用户确认。**

## 全量阶段授权（2026-10-19，优先于此前停止状态）

用户接受39状态试点用于诊断：一致率23/39=58.97%，不可判定0；缺失1状态记录为从到达队列抽样而非实际选择器决策的偏差，不补跑、不覆盖历史报告。现授权全量标签审计通过后直接训练，在10-26结束前完成验证选模和冻结，然后停止，不启封新盲测。

全量入口为`analysis/sar_selector_learning.py`，输出`results/sar_selector_learning_20261019/`。先对训练10-15至21、验证10-22至24的五条件进行v3母轨迹普查，仅收集各业务日[0,86400)内实际首次进入整图选择器的状态；按决策发生顺序分成最多8个等数量层，每层固定种子抽1个，不足8个取全部。每格名单及母轨迹哈希在分支回放前落盘。旧试点39状态仅用于诊断，新协议使用统一的扩充公开特征，不混合不同特征版本。所有标签仍为同状态三分支、后续v3、7200秒观察上限，记录严格标签、平局集合、实际时延及v3选择是否造成“最快方案≤300秒而v3>300秒”。执行异常单列；覆盖计划状态≥90%、不可判定率≤40%且重放审计通过才自动训练。

两个变体共享相同确定标签状态及公开特征，32/16隐藏单元MLP、200轮全批量Adam、学习率0.003、权重衰减0.001，种子1701/1702/1703，不扫参、不提前选轮。特征标准化和类别权重N/(3*n类)只用训练日；分类器使用加权交叉熵，回归器按该状态最快类别加权，预测三条log(1+时延)，完成分支SmoothL1、删失分支只惩罚低于已观测下界的预测。某训练类别完全缺失时停止报告，不伪造样本。报告各类别召回率及训练曲线。

报价为空是预测失败，不等同物理不可执行；学习与随机选择器可从同样三套已有方案选择，执行资源约束保持不变。随机均匀选择三方案、同三个种子。先跑各验证日全天闭环，共v3加6个学习模型加3个随机种子，每条件/日期10份记录；v3复用标签母轨迹P300/R300，图像均随访至少300秒。对6个学习模型按五条件、三日等权P300最高、R300最低选择，精确平局按分类器先于回归器、种子1701/1702/1703顺序；全部模型结果公开后冻结一个。另在同一批可判定验证决策上报告v3、两变体、随机期望、局部事后最优的P300/R300，明确该表不是全天可实现的全局上界。12-15至17盲测保持封存。
