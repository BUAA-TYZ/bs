# v3 方法冻结规格（2026-10-17，一页）

用户决定将 v3 三方案整图复核作为论文主方法，旧两方案保留为消融；开发中退化事实保留，不再调参。实现为 `analysis/sar_three_plan.py` 的 `ThreePlanChoice` / `CandidateEnv`，算法版本与已有 v3 记录一致。完整源码、运行器、生成器及报告脚本快照与 SHA-256 见 `freeze.json` 和 `source/`。

**输入与权限。** 每秒决策，读取当前可见待调度块、任务进度/等待年龄、节点计算与内存承诺、链路积压，以及未来 7200 秒公开接触预测（30 秒采样、60 秒刷新）。最多每源星 64 个候选块；不读取未来任务到达或计算前真实识别输出，只使用公开结果均值。当前实现共享全网公开状态，尚非仅邻居通信的去中心化系统。星上输入最多两跳；结果中继无环、最多 45 跳；原图地面分支按开发条件固定为 base/compute_4/compute_10/load_4 用 8 跳，load_2 用 45 跳。五条件全部方法使用相同任务、物理资源和处理服务率。

**三套报价。** 图像全部块可见且尚未开始时，生成：(1) 全部本地计算后结果中继；(2) CGS 生成的协同分配（允许混合地面计算）；(3) 唯一原图整体下传地面处理。各方案从同一公开资源日历复制试算；纳入已知积压、输入传输、计算排队和结果交付，星间窗口尾部保留一个接触扫描周期。前两者同时计算 FIFO 流水报价与旧整组报价，两者有效时取较大值；整组不可行而流水有效时保留流水值。地面方案传输 800 MB 唯一像素（16 包），拿齐原图后计算全部 64 窗；地面服务容量为星上 10 倍，计算倍率同时作用星地。报价为从图像就绪起的预计完整交付时延，包含已有等待和聚合延时。

**选择与承诺。** 选择最小有限、未截断的整图时延；精确平局按本地、CGS、地面顺序。全不可行则回退 CGS；图像已部分开始或未完整可见时也回退 CGS。同轮按等待年龄及块 ID 确定顺序，有限报价的胜出方案更新影子资源日历；该日历只用于估计，不改变公共路由或实际链路共享规则。原图方案一旦选择，按整图到齐屏障在地面执行，不重复本地计算。

**已知局限。** FIFO 影子日历不等于执行时的共享链路时隙；预测接触离散、路径重选、在途竞争和后续新任务均会使报价低估。开发 base 中 task_1 的 CGS 报价约 7.43 秒、实际约 311.64 秒即为反例。重计算收益部分来自地面方案（开发 compute_10 按时 31 图中 19 图走原图地面），不能全部解释为多星计算收益。不声称全条件最优、真实星历精度或硬件在轨可行性。

## 正式测试协议

- 2026-12-01 至 12-06，五条件 × 六方法 × 六日 = **180 次**；只运行每条件预先选定的一种强地面协议。带宽两条件只保留开发成绩。
- 同一组合成 TLE 从 2026-10-15 连续传播，不重设相位；沿用五港口、15 秒 SAR 采集、每源星间隔 30 秒、每窗口最多 3 图、成图延迟 60 秒。采集冷却从历元连续累计。按图像就绪 UTC 日归属任务，日内不删图；每个日仿真从空执行队列开始，24 小时到达加 301 秒随访。连续采集状态不等于跨测试日延续执行队列。
- 沿用输出负载生成器、seed=1701、每图局部序号/源星/就绪时间的确定性随机身份（原生成器与执行器均为 dt=0.01 秒）；各方法同一输出真值，负载倍率复制相同事件与真值。
- P300 为全部图像中 300 秒内完整结果落地比例；R300 为每图时延截断于 300 秒后平均，未完成记 300 秒。逐日报告，主汇总为日等权，不能按任务量加权替代。零任务日保留并标为不可定义，均值注明可定义日数。逐日 P300 胜/平/负与 R300 差值分别报告。
- 冻结后生成一次测试配置并记录哈希；任何运行失败仅报告，不据测试结果修改算法、路由、参数或协议，不新增变体。此批测试已用于固定 v3 的正式评估，不能再成为后续学习选择器的调参集。

开发最强对照差值见 `DEVELOPMENT_REPORT.md`；启动前工时估算见 `runtime_estimate.json`。最终逐日表、日均表和逐日配对表由冻结脚本自动写入 `REPORT.md` / `summary.json`，运行状态见 `progress.json`。
