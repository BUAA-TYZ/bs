## 协议范围

相对sar_temporal_study_20261017/main_config.json唯一配置变化是relay_max_hops由8变为45。
原图中继和结果中继均禁止回访已访问卫星，46星无环路径最多45次星间跳转；45是N-1的
安全界，不是新的硬件限制或调参值。星上输入卸载仍最多两跳，计算承诺和超时继续竞争不变。
轨道、180图负载、带宽、实测算力、内存、dt=0.01秒及P300/R300不变。
全部方法使用相同temporal公共路由；仿真核心源码与上一版相同。

公共协议改善不计为cgs_task_choice的新方法贡献。候选仍是CGS方案与全本地方案的整图复核，
不是MARL；CGS/HEFT仍为明确适配，非完整原论文复现。

## 地面对照退步诊断

丢失按时task_9/11/12，无新增按时。两次独立回放分别复现旧8跳和新协议全部逐任务结果：
[旧回放](ground_8hop_probe_7200/record.json)、[新回放](ground_probe_7200/record.json)。
各目录route_events.json.gz保留完整路径事件；报价观察见
[ground_quote_probe_7200/record.json](ground_quote_probe_7200/record.json)，观察器同样未改变结果。

- 旧路径让这三图的尾块在6539.00秒到达12号星，当时预测剩余下行窗口81秒；图像完成
  时延分别224.31、191.07、164.45秒，包含地面推理和聚合。
- 新路径使三图的代表尾块在6464.53/6464.66/6464.85秒到达10号星，随后等待到6730.54秒
  才再次转发，6738.13秒到达12号星时已无当前下行窗口。
- task_12在6415秒产生。其首个50 MB块的公开路由报价为4.79秒，经14次星间转发到12号星；
  10→27与27→12的保守接触截止均为相对50秒。报价只估计单包及已在传输的积压，没有为
  同图尚未进入下游的其他块预留服务，实际竞争和后续重规划可能使其赶不上该出口。
- task_9/11的首块报价也使用同一长链，预计分别61.82秒、21.82秒到地。逐包最早到达
  估计并非整图交付保证；没有证据将退步归因于地面GPU算力不足。
- 按执行器10秒几何采样单独核对，10→27和27→12到6490秒才断开，而上述报价扣除30秒
  预测保护量后的接纳截止是6465秒。尾片抵达10号星时尚有物理接触，但保守判断已经限制
  继续发送。12号星地面可见性到6620秒结束，6738.13秒抵达已迟。未为提高得分改小保护量。

这是路由预测与执行差异的机制证据，尚未用独立消融分离同图竞争、跨图竞争及窗口预测误差
各自的影响，也不能将保护量视为真实硬件必需的30秒延迟。没有为掩盖退步恢复8跳或改变
物理参数；后续公共路由改进必须对地面对照同样开放。
